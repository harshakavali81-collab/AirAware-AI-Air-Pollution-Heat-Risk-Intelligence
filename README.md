# AirAware AI — Static interactive preview

This **gh-pages** branch contains a self-contained HTML browser demonstration made from synthetic educational PM2.5 data. It runs without an API server, OpenAQ key, or forecast model.

- **Not a live data service**. The deployed React/FastAPI backend remains a separate Render service requiring owner activation.
- **Not real Hyderabad measurements**. Every plot and metric in this page is demo material.
- **Not a verified production link** until GitHub Pages reports a successful publication.

To activate this branch: repository **Settings → Pages → Build and deployment → Deploy from a branch → gh-pages → /(root) → Save**. Then check the Pages deployment status.

Expected GitHub Pages path, only after activation: `https://harshakavali81-collab.github.io/AirAware-AI-Air-Pollution-Heat-Risk-Intelligence/`.

Complete application source remains on `main`; this preview branch must not be confused with production hosting.
